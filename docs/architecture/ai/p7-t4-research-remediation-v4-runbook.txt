2. Validate the extracted bundle:

5. Revalidate Python, Tesla T4, pinned packages, and the bundle.
6. Download the exact base-model revision locally, then enable offline mode.
7. Run preflight:
   python scripts/training-pipeline-p7-t2-remediation-v4.py \
     --config config/p7-t2-training-pipeline-t4-remediation-v4.json \
     --decisions config/p6-t6-adapter-decisions.json \

     --run-output /content/p7-t2-research-remediation-v4-output

Training policy
- Four finite epochs maximum; no fixed maxSteps and no unapproved epoch increase.
- Float16 gradient scaler starts at 32768, based on the prior non-finite-gradient incident.
- Training must start from the exact fresh base model; no checkpoint resume is permitted.
- Validation is evaluated each epoch; early stopping patience is two epochs.
- Best checkpoint is selected only by validation loss.
- The evaluation split is never used for optimization, early stopping, or checkpoint selection.
- The approved v2 structured-output schema is training-only and remains inactive at runtime.

Stop conditions
- Stop on inventory/checksum/identity mismatch, wrong Python/GPU/model revision, package mismatch,
  CUDA error, NaN/Inf metric, missing best checkpoint, contract-holdout contamination, or schema failure.
- Do not repair generated output manually and do not resume a stopped candidate.
- Do not run P7-T4 until validated REAL_TRAINING_COMPLETE output is ingested into the repository.
