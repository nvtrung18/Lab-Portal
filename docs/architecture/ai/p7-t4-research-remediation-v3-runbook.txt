Execution order
1. Upload p7-t2-research-remediation-v3-t4.zip and extract it under /content.
2. Validate the extracted bundle with:
   python scripts/validate-p7-t2-research-remediation-v3-bundle.py --bundle-root /content/p7-t2-research-remediation-v3-t4
3. Install requirements/p7-t2-real-training-t4-cp313-requirements.txt with hashes.
4. Restart the whole Colab runtime.
5. Revalidate Python, Tesla T4, pinned packages, and the bundle.
6. Download the exact base-model revision into a local directory, then enable offline mode.
7. Run preflight:
   python scripts/training-pipeline-p7-t2-remediation-v3.py \
     --config config/p7-t2-training-pipeline-t4-remediation-v3.json \
     --decisions config/p6-t6-adapter-decisions.json \
     --dataset-manifest datasets/p7-research-synthetic-training-dataset-v3/manifest.json \
     --output /content/p7-t2-research-remediation-v3-output \
     --model-path /content/p7-t2-remediation-v3-model/cdbee75f17c01a7cc42f958dc650907174af0554 \
     --preflight-only
8. Run the same command without --preflight-only and with --source-commit set to the bundle manifest sourceCommit.
9. Validate real output:
   python scripts/validate-p7-t2-research-remediation-v3-bundle.py \
     --bundle-root /content/p7-t2-research-remediation-v3-t4 \
     --run-output /content/p7-t2-research-remediation-v3-output
10. Archive and download the complete output directory with a SHA-256 sidecar.

Training policy
- Four finite epochs maximum; no fixed maxSteps schedule.
- Validation is evaluated each epoch.
- Early stopping patience is two epochs.
- Best checkpoint is selected only by validation loss.
- Evaluation split is an isolated contract holdout and is never used for optimization,
  early stopping, or best-checkpoint selection.
- No automatic resumption from an unrelated candidate or config identity.

Stop conditions
- Stop on any bundle inventory mismatch, identity mismatch, wrong Python version,
  non-T4 GPU, model revision mismatch, package mismatch, CUDA error, NaN/Inf metric,
  missing best checkpoint, or contract-holdout contamination.
- Do not repair generated outputs manually.
- Do not run P7-T4 until validated REAL_TRAINING_COMPLETE output is ingested and bound.
