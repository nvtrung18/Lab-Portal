# P7-T2 portable real QLoRA execution on Google Colab Tesla T4

This additive profile preserves the approved dataset, exact base-model revision,
QLoRA parameters, seed, split separation, and 1000 configured steps. It changes
only quantization compute dtype and Trainer precision from bfloat16 to float16
because Tesla T4 does not provide native bfloat16 execution.

Use a private Google Colab notebook. Select the latest hosted `GPU T4` runtime
with CPython 3.13.15 before running these cells. Never add `--smoke`.

bundle = json.loads(Path("bundle-manifest.json").read_text(encoding="utf-8"))

    "python", "scripts/training-pipeline-p7-t2.py",
    "--config", "config/p7-t2-training-pipeline.json",
    "--decisions", "config/p6-t6-adapter-decisions.json",
    "--dataset-manifest", "datasets/p7-research-synthetic-training-dataset-v1/manifest.json",

    "--source-commit", bundle["sourceCommit"],

## Cell 9 - create and download the return archive

```python
from google.colab import files
from pathlib import Path
import zipfile

output = Path("/content/p7-t2-real-training-output")
archive_path = Path("/content/p7-t2-real-training-output.zip")
assert output.is_dir() and not archive_path.exists()
with zipfile.ZipFile(archive_path, "w", compression=zipfile.ZIP_DEFLATED, compresslevel=9) as archive:
    for path in sorted(item for item in output.rglob("*") if item.is_file()):
        info = zipfile.ZipInfo(
            f"p7-t2-real-training-output/{path.relative_to(output).as_posix()}",
            date_time=(1980, 1, 1, 0, 0, 0),
        )
        info.compress_type = zipfile.ZIP_DEFLATED
        info.external_attr = 0o100644 << 16
        archive.writestr(info, path.read_bytes(), compress_type=zipfile.ZIP_DEFLATED, compresslevel=9)
files.download(str(archive_path))
```

Do not download or return the base model or Hugging Face cache.
