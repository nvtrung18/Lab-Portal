## Cell 5 — provision only the approved immutable model revision

Keep Internet enabled for this cell. If the public snapshot ever requires
authentication, add `HF_TOKEN` through Kaggle Secrets; never place a token in
the notebook or bundle.

```python
from huggingface_hub import snapshot_download
from pathlib import Path
import json
import os

model_id = "Qwen/Qwen3-4B-Instruct-2507"
revision = "cdbee75f17c01a7cc42f958dc650907174af0554"
model_path = Path("/kaggle/working/p7-t3-model") / revision
assert not model_path.exists(), f"Refusing to reuse existing model directory: {model_path}"
downloaded = Path(
    snapshot_download(
        repo_id=model_id,
        revision=revision,
        local_dir=model_path,
        token=os.environ.get("HF_TOKEN"),
    )
).resolve()
assert downloaded == model_path.resolve(), (downloaded, model_path)

identity = {"identifier": model_id, "revision": revision}
(model_path / "p7-t3-model-identity.json").write_text(
    json.dumps(identity, ensure_ascii=False, sort_keys=True, indent=2) + "\n",
    encoding="utf-8",
)
print(model_path)
```

## Cell 9 — create the download ZIP

```python
from pathlib import Path
import zipfile

output_dir = Path("/kaggle/working/p7-t3-gap-run-approved")
download_zip = Path("/kaggle/working/p7-t3-gap-run-approved.zip")
assert output_dir.is_dir()
with zipfile.ZipFile(download_zip, "w", compression=zipfile.ZIP_DEFLATED, compresslevel=9) as archive:
    for path in sorted(item for item in output_dir.rglob("*") if item.is_file()):
        info = zipfile.ZipInfo(
            f"p7-t3-gap-run-approved/{path.relative_to(output_dir).as_posix()}",
            date_time=(1980, 1, 1, 0, 0, 0),
        )
        info.compress_type = zipfile.ZIP_DEFLATED
        info.external_attr = 0o100644 << 16
        archive.writestr(info, path.read_bytes(), compress_type=zipfile.ZIP_DEFLATED, compresslevel=9)
print(download_zip)
```

Download `/kaggle/working/p7-t3-gap-run-approved.zip`. The two JSON files
inside are candidate evidence and an uncompleted human-review input, not final
evidence. No human outcome is synthesized in this notebook.
